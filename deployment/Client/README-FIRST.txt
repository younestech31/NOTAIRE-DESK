NOTAIRE DESK — DEVELOPMENT PREVIEW

This is an early WPF application shell, not a production notarial system.
Do not use real contracts or personal data.

Requirements:
- Windows 10/11 x64
- Microsoft .NET 10 Desktop Runtime (WPF)

Run NotaireDesk.App.exe after installing the runtime.

The package is framework-dependent. It does not include PostgreSQL, office data, a document editor engine, authentication, or a production installer. Do not deploy it to an office workstation for operational use.
